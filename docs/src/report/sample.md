# `src/report/sample.rs`

## Purpose

Projects internal `SampleEvidence` into `signal.sample_evidence/v1`.

## Responsibilities

Validate the evidence/reference identity and map domain records into compact, deterministic public result records, including per-read event eligibility and exclusion reasons.

## Non-responsibilities

No scientific aggregation, evidence classification, consensus, serialization, logging, or filesystem publication.

## Status

Implemented.
